# Chatly Frontend - TypeScript & React

A modern, high-performance chat interface built with React and TypeScript. This client features real-time updates, sleek UI components, and strict type safety.

## ✨ Features
* **Real-time UI**: Instant message delivery and typing indicators.
* **Type Safety**: Fully migrated to TypeScript for robust development.
* **Responsive Design**: Built with Tailwind CSS and Shadcn/UI for a mobile-first experience.
* **State Management**: React Hooks (useContext/useReducer) and custom STOMP hooks.
* **Optimized Rendering**: Memoized components to prevent unnecessary WebSocket-triggered re-renders.

## 🛠 Tech Stack
* **React 18**
* **TypeScript**
* **Vite** (Build tool)
* **Tailwind CSS**
* **Shadcn/UI** (Components)
* **StompJS & SockJS** (WebSocket client)
* **Lucide React** (Icons)
